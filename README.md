# Rovers Worldwide

A mobile-first Next.js App Router starter for the Rovers Worldwide community.

## Getting started

Use Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run lint`, `npm run typecheck`, and `npm run build` to validate changes.

## Public assets

Put images in `public/assets/images/` and other hosted files in `public/assets/content/`. Reference files by their public URL (for example, `/assets/images/stadium-night.svg`), and use `next/image` for page imagery where practical.
