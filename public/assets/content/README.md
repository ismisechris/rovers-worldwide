# Public assets

Put reusable documents and other hosted, non-image files in this folder. Files here are served from `/assets/content/` (for example, `public/assets/content/guide.pdf` is available at `/assets/content/guide.pdf`).

Store images in `public/assets/images/`; reference them by their public URL, such as `/assets/images/stadium-night.svg`. Use `next/image` for page imagery where practical.
